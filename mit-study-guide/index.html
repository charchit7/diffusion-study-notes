First-Principles CompanionAn Introduction to Flow Matching & Diffusion Models

A from-zero study guide for the MIT 6.S183 / 2026 lecture notes by Peter Holderrieth & Ezra Erives. Built to teach you everything required to truly understand the notes — not to summarize them.

intuition first every symbol explained runnable PyTorch recursive prerequisites MathJax
Who this is for You know basic linear algebra, basic probability, and a little PyTorch. You have no background in differential equations, ODEs/SDEs, measure theory, stochastic processes, score matching, or variational inference. This guide assumes exactly that and builds every missing piece before it is used.

How to use this guide

  • Read in order. Each part assumes only the parts before it. Part 0 is pure prerequisites; by Part 13 you are reading the original notes line by line.
  • Colored boxes have fixed meanings. Intuition (the mental picture), Math (the formal object + equation breakdown), Watch out (a common confusion), Connection (where this returns later), and Prerequisite (a concept we pause to teach from scratch).
  • Run the code. Every major idea ends with the smallest possible PyTorch snippet, heavily commented, with the expected output written inline.
  • Equations are never dropped on you. Each one gets an Equation Breakdown: what every symbol means, its shape, and a geometric or probabilistic reading, derived step by step.

One thing to know before you start: ordering The MIT notes are flow-matching-first: they treat vector fields, ODEs, and flows as the primary object and derive diffusion and scores from them. This guide instead walks the historically intuitive DDPM-first road (Parts 4–9) and then arrives at flow matching (Part 10) as the clean generalization. Both reach the same destination. Throughout, each part flags the exact notes section it grounds in, so you can read the two side by side.
