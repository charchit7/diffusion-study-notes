Part 0Mathematical Foundations

Everything in flow matching and diffusion is built from five primitive ideas: vectors, functions of time, derivatives, probability densities, and the Gaussian. This part teaches each from zero, with the exact notation the MIT notes use, so that when later parts write \(u_t(x)\) or \(\nabla_x \log p_t(x)\) or \(\mathbb{E}_{z\sim p_{\text{data}}}[\cdot]\), every symbol is already familiar. Nothing here assumes more than high-school algebra.

Intuition for the whole field A generative model turns easy-to-sample noise into data by following a sequence of tiny steps. To describe "tiny steps along a direction" mathematically you need calculus (derivatives) and to describe "noise" and "a cloud of possible images" you need probability (densities, the Gaussian). Part 0 is just those two toolboxes.

0.1 Vectors: objects as points in \(\mathbb{R}^d\)

The MIT notes open with Key Idea 1: objects are vectors. An image with \(H\times W\) pixels and 3 color channels is a list of \(d = H\cdot W\cdot 3\) real numbers. Stack those numbers into a single column and you have a vector \(z \in \mathbb{R}^d\) — a single point in a \(d\)-dimensional space.

SymbolMeaningShape
\(\mathbb{R}\)the real numbers (any value on the number line)scalar
\(\mathbb{R}^d\)the set of all length-\(d\) lists of reals — "\(d\)-dimensional space"—
\(z \in \mathbb{R}^d\)one object (image/video/molecule) flattened to a vector\((d,)\)
\(d\)dimensionality; for a 64×64 RGB image \(d = 64\cdot64\cdot3 = 12288\)scalar
Mental model A \(28\times28\) grayscale MNIST digit (\(d=784\)) is one point in 784-dimensional space. "The set of all images that look like a 7" is a cloud of points in that space. Generation = produce a fresh point inside that cloud.

Operations you must recognize

  • Addition \(x + y\): elementwise; same shape in, same shape out. Geometrically, place vectors tip-to-tail.
  • Scaling \(\alpha x\) for scalar \(\alpha\): stretch (\(|\alpha|>1\)) or shrink (\(|\alpha|<1\)) the arrow; negative flips its direction.
  • Linear combination \(\alpha x + \beta y\): the single most common pattern in this course. The forward process \(x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon\) (Part 5) is literally a linear combination of a data point and a noise vector.
  • Norm \(\|x\| = \sqrt{\sum_i x_i^2}\): the length of the arrow / distance from the origin. The squared norm \(\|x\|^2\) is what appears in every loss function we will write.
  • Inner product \(x^\top y = \sum_i x_i y_i\): measures alignment; \(=0\) means perpendicular.

Tiny PyTorch example

import torch
torch.manual_seed(0)                  # reproducible: no security-sensitive RNG here, just teaching

x = torch.tensor([3.0, 4.0])          # a vector in R^2, shape (2,)
y = torch.tensor([1.0, 0.0])          # shape (2,)

print(x + y)                          # tensor([4., 4.])   elementwise add, shape (2,)
print(2.0 * x)                        # tensor([6., 8.])   scaling
print(x.norm())                       # tensor(5.)         sqrt(3^2+4^2)=5
print(torch.dot(x, y))                # tensor(3.)         inner product 3*1+4*0

0.2 Functions, and functions of time

A function \(f: A \to B\) takes an input from set \(A\) and returns an output in set \(B\). The arrow notation tells you the shapes. Two function types dominate this course:

The two function signatures you will see everywhere \[ \underbrace{X:\;[0,1]\to\mathbb{R}^d}_{\text{a trajectory: time}\,\to\,\text{position}}, \qquad\qquad \underbrace{u:\;\mathbb{R}^d\times[0,1]\to\mathbb{R}^d}_{\text{a vector field: (position, time)}\,\to\,\text{velocity}} \]
ObjectReads asReturns
\(X_t\) or \(X(t)\)"where the particle is at time \(t\)"a point in \(\mathbb{R}^d\)
\(u_t(x)\) or \(u(x,t)\)"the velocity to use if you are at position \(x\) at time \(t\)"a vector in \(\mathbb{R}^d\)
\(t\in[0,1]\)time, conventionally normalized to the unit intervalscalar
Why both? The vector field \(u_t\) is the rule ("at this spot, move this way"); the trajectory \(X_t\) is the path you trace when you obey the rule. A neural network will learn the rule \(u_t\); sampling = following the rule to trace a path from noise to data. This single distinction is the heart of Parts 1, 7, and 10.

0.3 Derivatives: the rate of change

The derivative of a function answers: if I nudge the input a little, how much does the output change, and in what direction?

Scalar case

Definition (derivative as a limit) \[ f'(t) \;=\; \frac{d f}{d t} \;=\; \lim_{h\to 0}\frac{f(t+h)-f(t)}{h}. \]

Read it literally: take a small step \(h\) in the input, measure the change in output \(f(t+h)-f(t)\), divide by the step size to get a rate, then shrink \(h\) to zero. The result \(f'(t)\) is the instantaneous slope.

Picture Zoom into the graph of \(f\) at time \(t\) until the curve looks straight. The slope of that straight line is \(f'(t)\). "Velocity" is exactly the derivative of position with respect to time — which is why \(\frac{d}{dt}X_t\) (Part 1) is a velocity vector.

Vector case: position in, vector out

If \(X_t \in \mathbb{R}^d\) is a trajectory, its derivative \(\frac{d}{dt}X_t \in \mathbb{R}^d\) is taken componentwise — one slope per coordinate — and the resulting vector is the velocity of the moving point. This is the left-hand side of every ODE in this course.

Gradient: scalar out, vector in

When the input is a vector \(x\in\mathbb{R}^d\) and the output is a single number \(f(x)\in\mathbb{R}\), the analogue of the derivative is the gradient \(\nabla_x f(x) \in \mathbb{R}^d\): the vector of partial derivatives, one per input coordinate.

Gradient \[ \nabla_x f(x) \;=\; \left(\frac{\partial f}{\partial x_1},\ \frac{\partial f}{\partial x_2},\ \dots,\ \frac{\partial f}{\partial x_d}\right)^\top \in \mathbb{R}^d. \] Each \(\frac{\partial f}{\partial x_i}\) is just the scalar derivative taken while holding every other coordinate fixed.
Where this returns The score function (Part 3) is a gradient: \(\nabla_x \log p_t(x)\). It points in the direction along which the (log) density increases fastest — i.e. "toward more probable data." Score matching trains a network to output this vector. You cannot read Part 3, 4, 8, or 9 without this definition, so make sure \(\nabla_x\) means "vector of slopes, one per pixel."

PyTorch: autograd computes gradients for you

import torch

x = torch.tensor([2.0, -3.0], requires_grad=True)  # track operations on x
f = (x ** 2).sum()                                  # f(x) = x1^2 + x2^2, a scalar
f.backward()                                        # fill x.grad with df/dx
print(x.grad)                                       # tensor([ 4., -6.])  since df/dxi = 2*xi
# Check by hand: d/dx1 (x1^2+x2^2) = 2*x1 = 4; d/dx2 = 2*x2 = -6.  matches.

0.4 Integrals: adding up infinitely many tiny pieces

An integral \(\int_a^b g(t)\,dt\) is the continuous sum of \(g(t)\) over the interval, weighted by the infinitesimal width \(dt\). Two facts are all we need:

  • Integration undoes differentiation (Fundamental Theorem): if \(X_t\) has velocity \(u_t\), then \(X_b = X_a + \int_a^b u_t\,dt\). Following a velocity over time = integrating it. This is why "simulating an ODE" (Part 1) literally means "approximating an integral."
  • A probability density integrates to 1: \(\int_{\mathbb{R}^d} p(x)\,dx = 1\) (next section).
Euler's method in one line We almost never integrate exactly. Instead we approximate \(\int_t^{t+h} u_s\,ds \approx h\,u_t(X_t)\) — "velocity now times the time step." That single approximation, repeated, is the Euler method and the backbone of every sampler in this guide (Parts 1, 5, 6, 10).

0.5 Probability from first principles

Random variable and density

A random variable is a quantity whose value is uncertain. For continuous values in \(\mathbb{R}^d\), the uncertainty is described by a probability density \(p:\mathbb{R}^d\to\mathbb{R}_{\ge 0}\). The density is not a probability itself; it is a probability per unit volume. Probabilities come from integrating it over a region:

Density axioms \[ p(x)\ge 0 \quad\text{for all }x,\qquad\qquad \int_{\mathbb{R}^d} p(x)\,dx = 1. \] \(\Pr[X \in A] = \int_A p(x)\,dx\) for any region \(A\).

The notation \(z \sim p_{\text{data}}\) (MIT Key Idea 2) reads "\(z\) is a random sample drawn from the density \(p_{\text{data}}\)." The entire goal of the course, stated in Part 0 language: build an algorithm that outputs samples \(z\sim p_{\text{data}}\) given only a finite dataset \(z_1,\dots,z_N\sim p_{\text{data}}\).

Expectation

Expectation (the "average value") \[ \mathbb{E}_{x\sim p}\big[g(x)\big] \;=\; \int g(x)\,p(x)\,dx \;\approx\; \frac{1}{N}\sum_{i=1}^N g(x_i),\quad x_i\sim p. \]

The right-hand approximation — average over samples — is how every loss in this course is actually computed: we cannot do the integral, so we draw a minibatch and average. When you see \(\mathbb{E}[\cdot]\) in a training objective (Parts 3, 5, 10), mentally replace it with "average this over the batch."

Common confusion A density \(p(x)\) can be larger than 1 (it is per-volume, not a probability). Only its integral is constrained to 1. A narrow Gaussian has a tall peak with \(p(x)\gg 1\) near the mean.

Conditional and marginal densities

For a pair \((x,y)\): the joint \(p(x,y)\), the conditional \(p(x\mid y)=p(x,y)/p(y)\) ("density of \(x\) once \(y\) is fixed"), and the marginal \(p(x)=\int p(x,y)\,dy\) ("integrate out \(y\)"). The flow-matching "marginalization trick" (Part 10) is built entirely on moving between a conditional path \(p_t(x\mid z)\) and its marginal \(p_t(x)=\int p_t(x\mid z)\,p_{\text{data}}(z)\,dz\) — so lock in these three words now.

0.6 The Gaussian — the one distribution to know cold

Noise in every diffusion model is Gaussian. The density in \(d\) dimensions with mean \(\mu\in\mathbb{R}^d\) and covariance \(\Sigma\in\mathbb{R}^{d\times d}\):

Multivariate Gaussian \[ \mathcal{N}(x;\mu,\Sigma)=\frac{1}{\sqrt{(2\pi)^d\det\Sigma}} \exp\!\Big(-\tfrac12 (x-\mu)^\top \Sigma^{-1}(x-\mu)\Big). \]
SymbolMeaning
\(\mu\)mean — the center of the cloud
\(\Sigma\)covariance — how the cloud is stretched/correlated in each direction
\(I_d\)\(d\times d\) identity; \(\mathcal{N}(0,I_d)\) is "isotropic" standard noise
The only special cases we use Almost always \(\Sigma = \sigma^2 I_d\) (every coordinate independent, same spread). Then the Gaussian is just "each coordinate is an independent bell curve with std \(\sigma\)." The standard normal \(\mathcal{N}(0,I_d)\) is our \(p_{\text{init}}\): the easy distribution we start sampling from.

Two properties that make the math work

A — Reparameterization \[ x\sim\mathcal{N}(\mu,\sigma^2 I) \iff x=\mu+\sigma\,\varepsilon,\quad \varepsilon\sim\mathcal{N}(0,I). \] Sampling a Gaussian = take fixed standard noise and shift+scale it. This lets gradients flow through the sampling step (used in the VAE, Part 12, and in every forward process).
B — Sum of independent Gaussians If \(a\sim\mathcal{N}(0,\sigma_a^2 I)\) and \(b\sim\mathcal{N}(0,\sigma_b^2 I)\) independently, then \(a+b\sim\mathcal{N}(0,(\sigma_a^2+\sigma_b^2)I)\). Variances add. This is the one identity that collapses the DDPM multi-step forward process into a single closed form (Part 5).

PyTorch: sampling and reparameterization agree

import torch
torch.manual_seed(0)

mu, sigma = 5.0, 2.0
direct = torch.normal(mean=mu, std=sigma, size=(100000,))      # sample N(5, 2^2) directly

eps = torch.randn(100000)                                      # eps ~ N(0,1), shape (100000,)
reparam = mu + sigma * eps                                     # property A: same distribution

print(direct.mean().item(),  direct.std().item())   # ~5.00  ~2.00
print(reparam.mean().item(), reparam.std().item())  # ~5.00  ~2.00  (matches)

0.7 KL divergence (a teaser for Parts 10 & 12)

To say "distribution \(q\) is close to distribution \(p\)" we use the Kullback–Leibler divergence \(D_{\mathrm{KL}}(q\,\|\,p)=\mathbb{E}_{x\sim q}\big[\log\frac{q(x)}{p(x)}\big]\ge 0\), with equality iff \(q=p\). You only need three facts: it is \(\ge 0\), it is zero exactly when the distributions match, and it is not symmetric. The VAE objective (Part 12) and the variational view of diffusion are KL minimizations. We derive the Gaussian closed form when we need it.
